# **Project Requirements Document: Coder's Todo App (CodeTask / DevDocket / GitDone - TBD)**

The following table outlines the detailed functional requirements for the Coder's Todo web application.

| Requirement ID | Description                      | User Story                                                                                                      | Expected Behavior/Outcome                                                                                                                                                                |
| :------------- | :------------------------------- | :-------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Core Task Management** |                          |                                                                                                                 |                                                                                                                                                                                          |
| FR001          | Create New Task                  | As a coder, I want to create a new task with a title and optional details so I can track my work items.           | System provides a clear UI element (e.g., button, form) to add a new task. Requires a Title. Allows optional Description, Due Date, Priority. The new task appears in the user's task list. |
| FR002          | View Task List                   | As a coder, I want to see my list of tasks, including their status and key details, so I know what to work on.     | System displays tasks associated with the logged-in user. Shows Title, Completion Status, Priority, Due Date, and associated Project Tag(s).                                              |
| FR003          | Edit Existing Task               | As a coder, I want to modify the details of a task (title, description, due date, priority etc.) if things change. | System allows selecting an existing task and editing its properties through a form or inline editing. Changes are saved and reflected in the task list.                               |
| FR004          | Delete Task                      | As a coder, I want to delete a task if it's no longer relevant or was created by mistake.                        | System provides a mechanism (e.g., button, menu option) to permanently remove a task. A confirmation step might be included.                                                             |
| FR005          | Mark Task Complete/Incomplete    | As a coder, I want to mark tasks as complete when finished and be able to reopen them if necessary.             | System allows toggling the completion status of a task (e.g., via a checkbox). Visual distinction between complete and incomplete tasks (e.g., strikethrough, different color).      |
| FR006          | Add/Manage Sub-tasks             | As a coder, I want to break down complex tasks into smaller, manageable sub-tasks for better tracking.            | System allows creating child tasks (sub-tasks) linked to a parent task. Sub-tasks can be viewed under the parent and marked complete independently. Parent task may show sub-task progress. |
| **Project Organization** |                          |                                                                                                                 |                                                                                                                                                                                          |
| FR007          | Create/Manage Projects           | As a coder, I want to define project names (tags) so I can categorize and organize my tasks effectively.        | System provides an interface to create new project tags. Optionally, allow viewing, editing, or deleting existing project tags.                                                      |
| FR008          | Assign Task to Project(s)        | As a coder, I want to assign one or more project tags to a task during creation or editing for organization.      | Task creation/edit form includes a mechanism (e.g., dropdown, multi-select, text input with autocomplete) to associate task with existing project tags.                               |
| FR009          | Filter Tasks by Project          | As a coder, I want to filter my task list to view only the tasks associated with a specific project.              | System provides UI controls (e.g., sidebar list, dropdown filter) to select a project, updating the task list to show only tasks with that tag. An "All Projects" view is available. |
| **Coder-Specific Features** |                        |                                                                                                                 |                                                                                                                                                                                          |
| FR010          | Add/Edit Time Estimation         | As a coder, I want to add an estimated time (e.g., hours, points) to complete a task for planning purposes.      | Task create/edit interface includes a field for numeric time estimation. Estimated time is displayed alongside the task.                                                              |
| FR011          | Add/Edit Task Type               | As a coder, I want to categorize tasks by type (e.g., Bug, Feature, Refactor, Chore, Research) for context.      | Task create/edit interface includes a field (e.g., dropdown) to select or define a task type. Type is displayed with the task, possibly allowing filtering/sorting by type later.   |
| FR012          | Add/Edit Code Snippet            | As a coder, I want to attach relevant small code snippets or technical notes directly to a task for reference. | Task create/edit interface includes a dedicated text area, ideally supporting Markdown with syntax highlighting, for code snippets/notes. Snippet is viewable in task details.          |
| FR013          | Add/Edit Relevant Links          | As a coder, I want to link tasks to external URLs (e.g., GitHub issues, docs, Figma) for easy access.            | Task create/edit interface allows adding one or more URLs with optional labels. Links are displayed and clickable within the task details.                                             |
| **Authentication** |                               |                                                                                                                 |                                                                                                                                                                                          |
| FR014          | User Authentication (Sign In)    | As a user (coder/friend), I want to sign in securely using my Google account to access my personal tasks & projects. | System provides a "Sign in with Google" button triggering the Google OAuth 2.0 flow. Upon successful authentication, the user is logged in, and their specific data is loaded.         |
| FR015          | User Session Management          | As a user, I want the application to remember I'm logged in across browser sessions until I explicitly sign out. | System securely manages user sessions (e.g., using cookies or tokens) after login, maintaining the logged-in state.                                                              |
| FR016          | User Sign Out                    | As a user, I want to be able to sign out of the application to end my session securely.                         | System provides a clearly accessible sign-out button/link that terminates the user's session and redirects to a logged-out state (e.g., login page).                                 |

This adapted table should give you a clear set of functional requirements tailored to the Coder's Todo App concept using the Nuxt.js stack we defined.
